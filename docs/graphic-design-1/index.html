Quem Somos

A Horizonte Tech é uma startup de tecnologia fundada em 2020 com a missão de democratizar o acesso a soluções inovadoras. Nossas letras entrelaçadas representam conexão, colaboração e a intersecção entre tecnologia e humanidade.

O nome "Horizonte" simboliza visão de futuro, expansão de possibilidades e a busca constante por novas fronteiras. Juntamente com "Tech", formamos uma identidade que une inovação e propósito.

Diretrizes de Marca

Regras para uso correto da identidade visual

Espaço Mínimo

Mantenha uma área livre ao redor do logo equivalente a metade da altura do símbolo (X/2) para garantir legibilidade e destaque.

Tamanho Mínimo

O logo não deve ser reduzido a menos de 80px de largura para uso digital e 25mm para impressão, para garantir a legibilidade.

Fundos Inadequados

Evite aplicar o logo em fundos com baixa contrate (ex: foto colorida ou padrões complexos). Use sempre versões monocromáticas quando necessário.

Distorção Proibida

Nunca distorça, gire, estique ou comprima o logo. Mantenha sempre as proporções originais para preservar a identidade da marca.

Cores Alternativas

Em casos de impressão em uma cor, use a versão monocromática. Para fundos claros, use a versão em preta. Para fundos escuros, use a versão em branca.

Tipografia Consistente

Use sempre a família Inter para todos os textos relacionados à marca. Mantenha os pesos e tamanhos definidos no manual para uniformidade.
